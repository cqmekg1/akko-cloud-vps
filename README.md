## 选 VPS 套餐之前，先想清楚三件事

我见过太多人买 VPS 套餐的方式是这样的：看到某商家年付 99 块就冲了，买完发现流量 200G 一个月根本不够用，又看到另一家带宽大就又换一台，最后账上一堆孤儿实例。其实下手之前，把这三件事想明白能省掉 80% 的折腾：

**第一，你的业务是吃带宽还是吃延迟。** 跑站、做反向代理、SSH 跳板这种场景，对带宽其实没那么挑，但对延迟和回程线路非常敏感——尤其是国内用户访问海外服务器的时候，回程走不走 CN2 GIA，体感差出一个太平洋。如果你是搞直播转发、大文件中转、图床视频这类，那就是反过来，带宽和月流量才是命根子。

**第二，你的预算是月付还是年付。** 这听起来像废话，但实际差异很大。同一台机器，月付 50 元和年付 299 元的差价能差出将近一半。问题是年付有资金占用和商家跑路风险，月付又贵又反复续费麻烦。我的经验是：第一次跑测用月付或季付试水，稳定跑两个月业务不掉链子，再果断转年付锁定价格。

**第三，机房位置决定了一切。** 美西圣何塞是国内访问的"老熟人"，延迟低、线路成熟；德国法兰克福适合做欧洲业务或者追求 CMIN2 的移动用户；英国伦敦则是少见的欧洲 CN2 GIA 节点，做外贸独立站对接欧洲客户时很香。选错机房，再好的套餐配置也是白搭。
